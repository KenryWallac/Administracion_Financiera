¿Cómo funciona?

Por seguridad, los navegadores no pueden acceder directamente a tu correo. Aquí puedes pegar el texto de un correo de notificación bancaria o cargar un archivo JSON con varios correos. La app detectará automáticamente montos, fechas y tipos.

💡 Para integración real con Gmail/Outlook, se requiere un backend Node.js + OAuth2. Consulta el archivo server.js incluido como plantilla.
